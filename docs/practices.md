# Practices

* Every tuesday a team meeting to see where we are and what everyone does next.
* Communication on whatsapp and discord.
* Whatsapp used for important notifications: whenever someone starts working on the project and afterwards what they did and what they do next, and if they need help.
* Discord whenever actively doing the project.
* Main branch only for working code. Feature branches merged to Dev branch.
* Use "add code" instead of "added code" in commit messages (imperative).
* English used for the project.
